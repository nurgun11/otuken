# Фестиваль Отюкен - Международный этнокультурный фестиваль

Современный лендинг для международного этнокультурного фестиваля Отюкен с поддержкой четырех языков: русского, английского, монгольского и турецкого.

## Особенности

- Современный адаптивный дизайн
- Многоязычный интерфейс (RU, EN, MN, TR)
- Форма регистрации на фестиваль
- Анимации и интерактивные элементы
- Оптимизированная производительность

## Структура проекта

```
├── index.html          # Главная страница
├── css/
│   └── style.css      # Стили
├── js/
│   ├── main.js        # Основной JavaScript
│   └── translations.js # Переводы
└── images/            # Изображения
    ├── logo.png
    └── hero-bg.jpg
```

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# Если у вас установлен Python
python -m http.server 8000

# Если у вас установлен Node.js
npx serve
```

## Требования к изображениям

Для корректной работы сайта необходимо добавить следующие изображения в директорию `images/`:

- `logo.png` - логотип фестиваля (рекомендуемый размер: 200x50px)
- `hero-bg.jpg` - фоновое изображение для главного экрана (рекомендуемый размер: 1920x1080px)

## Настройка

### Добавление новых переводов

Для добавления новых переводов отредактируйте файл `js/translations.js`. Добавьте новый объект с переводами в объект `translations`:

```javascript
const translations = {
    // Существующие переводы...
    'new-lang': {
        'key': 'translation'
    }
};
```

### Изменение стилей

Все стили находятся в файле `css/style.css`. Основные цвета и переменные определены в начале файла:

```css
:root {
    --primary-color: #2C3E50;
    --secondary-color: #E74C3C;
    --accent-color: #F1C40F;
    /* ... */
}
```
