# Otuken Festival - WordPress Theme

Тема WordPress для сайта международного этнокультурного фестиваля Отюкен.

## Особенности темы

- Многоязычность (русский, английский, турецкий, монгольский)
- Адаптивный дизайн для всех устройств
- Новостной блок с поддержкой категорий и тегов
- Форма регистрации участников
- Интерактивная программа фестиваля
- Поддержка кастомизации через WordPress Customizer

## Требования

- WordPress 5.8 или выше
- PHP 7.4 или выше
- MySQL 5.6 или выше

## Установка

1. Скачайте архив с темой.
2. В панели администратора WordPress перейдите в раздел "Внешний вид" -> "Темы".
3. Нажмите кнопку "Добавить новую", затем "Загрузить тему".
4. Выберите скачанный архив и нажмите "Установить".
5. После установки нажмите "Активировать".

## Настройка темы

### Главная страница

1. Создайте новую страницу и назовите ее "Главная".
2. В панели администратора перейдите в "Настройки" -> "Чтение".
3. Выберите "Статическая страница" в качестве главной страницы.
4. Выберите созданную страницу "Главная" в выпадающем списке.

### Меню навигации

1. Перейдите в "Внешний вид" -> "Меню".
2. Создайте новое меню и добавьте нужные страницы.
3. Назначьте созданное меню в качестве "Главного меню".

### Логотип и фавикон

1. Перейдите в "Внешний вид" -> "Настроить".
2. В разделе "Идентичность сайта" загрузите логотип и фавикон.

### Настройка многоязычности

Тема имеет встроенную поддержку многоязычности. Для переключения языка используются кнопки в шапке сайта. Все переводы хранятся в файле `js/translations.js`.

```

├── archive.php              # Шаблон архивных страниц
├── footer.php               # Шаблон подвала сайта
├── functions.php            # Функции темы
├── functions-news.php       # Функции для новостного раздела
├── header.php               # Шаблон шапки сайта
├── index.php                # Основной шаблон

├── screenshot.png           # Скриншот темы
├── css/                     # Дополнительные CSS-файлы
├── js/                      # JavaScript-файлы
│   ├── main.js              # Основной JS-файл
│   └── translations.js      # Файл с переводами
└── images/                  # Изображения темы
```

## Создание новостей

1. В панели администратора перейдите в "Записи" -> "Добавить новую".
2. Заполните заголовок, содержание и выберите категорию.
3. Загрузите миниатюру записи.
4. Опубликуйте запись.

## Форма регистрации

Форма регистрации доступна через модальное окно при нажатии на кнопку "Зарегистрироваться" на главной странице. Все заявки сохраняются в разделе "Регистрации" в панели администратора.
